# W.tv — точное время VOD

Юзерскрипт для Tampermonkey / Violentmonkey, который показывает точную дату и время начала стрима (`ДД.ММ.ГГГГ ЧЧ:ММ:СС`) для записей (VOD) на [w.tv](https://w.tv).

## Что делает

- **Карточки VOD** (списки видео канала, главная и т.д.): добавляет бейдж с точным временем в левый нижний угол превью.
- **Блок «Последняя трансляция»** на странице канала: заменяет относительную дату («2 дня назад») на точное время.
- **Страница VOD** (`/<канал>/videos/<id>`): заменяет дату окончания (`ДД.ММ.ГГГГ`) на точное время начала или добавляет его отдельной строкой.
- При наведении на время показывается подсказка с началом и концом стрима.

Время выводится в локальном часовом поясе браузера.

## Установка

1. Установите [Tampermonkey](https://www.tampermonkey.net/) или [Violentmonkey](https://violentmonkey.github.io/).
2. Создайте новый скрипт и вставьте содержимое `.user.js`, затем сохраните.
3. Откройте или обновите любую страницу на `w.tv`.

## Настройки

В начале скрипта, в блоке `НАСТРОЙКИ`:

| Параметр | По умолчанию | Описание |
|---|---|---|
| `TIME_FIELD` | `'startedAt'` | Какое время показывать: `'startedAt'` — начало стрима, `'finishedAt'` — окончание |
| `REPLACE_VOD_PAGE_DATE` | `true` | `true` — заменить дату на странице VOD, `false` — добавить точное время отдельной строкой |
| `REPLACE_LAST_BROADCAST_DATE` | `true` | Заменять относительную дату в блоке «Последняя трансляция» |

## Как работает

1. Перехватывает ответы `fetch` / `XMLHttpRequest` страницы к `streams-search-service.w.tv` и собирает из JSON объекты стримов (`streamId`, `startedAt`, `finishedAt`).
2. Если данных о видео ещё нет, сам запрашивает их через `GM_xmlhttpRequest`:
   - канал: `profiles-service.w.tv/.../profiles/by-nickname/<ник>` → `userId` → `streams-search-service.w.tv/.../channels/<userId>/streams`;
   - одиночный VOD: `streams-search-service.w.tv/.../streams/<streamId>`.
3. `MutationObserver` и периодическая проверка (раз в 3 с) перерисовывают метки при SPA-переходах.

## Разрешения

- `GM_xmlhttpRequest` — прямые запросы к API w.tv (`@connect streams-search-service.w.tv`, `profiles-service.w.tv`).
- `unsafeWindow` — перехват `fetch`/XHR в контексте страницы.

## Ограничения

- Скрипт завязан на текущую разметку (`data-testid`, `h4.h4-stable`) и API w.tv — после изменений на сайте может перестать работать.
- Используется недокументированное API.
